# BDO Vision 1.12.0

Extract the Windows ZIP completely, then open OPEN-BDO-VISION.bat. Python is included; Tesseract with English is required separately. Close other Vision copies before starting. Existing history stays in the protected profile.

- Place Mode selects the nearby tool from verified OCR on the first scan and starts its countdown. Subsequent durability use confirms the selection.
- Timed 1.5-second label comparisons assist uncertain tool identification.
- Guild, Daily and Bonus objective counters support wrapped lines and show last verified progress. Guild alerts default to 95%; tool warnings default to ten seconds.
- Planner sends include a last-seen guild snapshot with timestamp, without estimated quest progress.
- Loot, silver, grind and crafting sessions, equipment tools, tray controls and history remain included.

250 isolated regressions and extracted Windows checks validate this release. OCR still needs visible readable text; bright backgrounds, overlapping labels or covered widgets can remain unresolved. Positional tool selection is provisional until use is confirmed. No perfect-accuracy or zero-FPS-impact guarantee is made. Source, checksums and previous checkpoints are retained for recovery.
